# Support Information 🛠️ (HYDRA-UMC-EDITOR-STL)

Thank you for using HYDRA-UMC-EDITOR-STL! Here is how you can get help:

## 📺 Video Tutorials & Demos

The best way to see how this tool browses and edits the HYDRA-UMC
ecosystem's own STL model libraries is through our official YouTube
channel: [youtube.com/@electrohobby3d](https://youtube.com/@electrohobby3d)

## ✉️ Direct Technical Inquiries

For questions about pointing this tool at a custom checkout layout, or
anything not covered by the README:
Email: `electrohobby3d@gmail.com`

## 🐛 Bug Reports

If `hydra-umc-editor-stl --cli parts` lists a part that doesn't actually
exist on disk, or a `transform`/`replace`/`remove`/`add` operation fails
against a real, valid STL file, please open a **GitHub Issue** in this
repository - include the exact command you ran and its full output.
*Please search existing issues before opening a new one.*

## ❌ What is NOT support?

- This tool only edits the real files already present under
  HYDRA-UMC-STUDIO's/HYDRA-UMC-SUITE's own model libraries - it does not
  design new 3D models from scratch (use a real CAD tool for that, then
  add the exported STL here).
- Please do not use Issues for general STL/CAD modeling questions -
  those belong on a general 3D-printing/CAD community, not this tool's
  own tracker.
